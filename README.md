# AgroCult ERP Downloads

This public repository contains only downloadable AgroCult ERP releases.
The application source code is maintained separately in a private repository.

## Install

1. Install Java 17 or newer.
2. Download `AgroCult_Launcher.jar` from the latest release.
3. Start it with:

   ```bash
   java -jar AgroCult_Launcher.jar
   ```

The launcher downloads and starts the current `AgroCult_ERP.jar` automatically.
